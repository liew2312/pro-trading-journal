# Manga Capture สำหรับ Android

ต้นแบบแอปเปิดเว็บ HTTPS แล้วแคปช่วงที่เลือกเป็น PDF ทำงานแยกจากเว็บบันทึกเทรดเดิม รองรับ Android 8 ขึ้นไป

## ติดตั้งและใช้งาน

ไฟล์ทดลองอยู่ที่ `build/manual/MangaCapture.apk` ส่งไฟล์ไปมือถือแล้วเปิดติดตั้ง หาก Android ถามให้อนุญาตติดตั้งจากแอปที่ใช้เปิดไฟล์ สามารถอนุญาตเฉพาะครั้งที่ต้องใช้แล้วปิดสิทธิ์กลับได้

1. เปิดแอป ลิงก์ Go-Manga ตัวอย่างจะถูกใส่ให้แล้ว เปลี่ยนเป็นลิงก์ HTTPS อื่นได้
2. ปิดโฆษณาที่ทับภาพบนหน้าเว็บ และเลื่อนอ่านให้ภาพโหลดครบ
3. เลื่อนให้ตำแหน่งเริ่มอยู่ที่เส้นสีเขียวกลางจอ กด **เริ่มตรงเส้น**
4. เลื่อนให้ตำแหน่งจบอยู่ที่เส้นเดียวกัน กด **จบตรงเส้น**
5. ใช้ **ขอบภาพ** ปรับเปอร์เซ็นต์ที่ตัดจากซ้ายและขวา ดูแนวขอบจากพื้นที่ทึบด้านข้าง
6. **ดูตัวอย่าง** แสดงทั้งส่วนต้นและส่วนท้าย จุดเริ่มอยู่ขอบบนภาพแรก จุดจบอยู่ขอบล่างภาพที่สอง
7. **บันทึก PDF** เลือก A4 หรือหน้ายาว จากนั้นเลือกโฟลเดอร์ปลายทางผ่านหน้าบันทึกไฟล์ของ Android

แอปเลื่อนโหลดรูปตามช่วงก่อนแคป และรอภาพที่อยู่ในจอ หากยังโหลดไม่ได้หลังรอ จะหยุดพร้อมข้อความ ภาพถูกวาดลง PDF ทีละส่วนเพื่อลดการใช้หน่วยความจำ ปุ่มยกเลิกใช้ระหว่างเตรียมภาพและแคปได้

## ข้อจำกัดรุ่นทดลอง

- สร้างและตรวจลายเซ็น APK ผ่านแล้ว ยังไม่ได้ทดสอบบนเครื่องจริงหรือ emulator
- หน้ายาวจำกัดความสูง 14,000 PDF points ต่อหน้า ถ้ายาวกว่านี้จะแบ่งหลายหน้า
- โฆษณาลอยอาจติดในภาพ ต้องปิดจากเว็บก่อน แอปไม่ได้มีตัวกรองโฆษณา
- เว็บที่เปลี่ยนความสูงหลังโหลดภาพอาจทำให้จุดที่เลือกคลาดเคลื่อน ควรโหลดภาพครบก่อนเลือกจุด
- ตัวอย่างแสดงส่วนต้นและส่วนท้าย ควรเปิด PDF ตรวจรอยต่อหลังบันทึก
- หน้าเว็บที่เลื่อนในกรอบย่อย, เล่นวิดีโอ, ย้ายองค์ประกอบขณะเลื่อน หรือป้องกันการแคป อาจไม่รองรับ
- PDF แบบภาพจะเลือกหรือค้นหาข้อความไม่ได้ และรอยแบ่งหน้า A4 อาจตัดกลางภาพ
- ไม่ขอสิทธิ์เข้าถึงไฟล์ทั้งเครื่อง ใช้หน้าบันทึกของ Android โดยตรง ไม่มีระบบอัปโหลดภาพไปเซิร์ฟเวอร์ของแอป
- APK ใช้กุญแจสำหรับการพัฒนา ไม่ใช่รุ่นเผยแพร่ Play Store ใช้กับเนื้อหาที่มีสิทธิ์เก็บสำเนา

## สร้าง APK บน Windows

ต้องมี JDK (ใช้ที่มากับ Android Studio ได้) และ Android SDK พร้อม platform/build-tools

```powershell
./build-apk.ps1 -AndroidSdk 'C:/Users/Preeya/AppData/Local/Android/Sdk'
```

สคริปต์สร้าง APK พร้อมลงนามสำหรับทดสอบไว้ใน `build/manual/` โดยไม่ต้องดาวน์โหลด Gradle เพิ่ม อีกทางเปิดโฟลเดอร์นี้ด้วย Android Studio แล้วใช้ Gradle 8.9 และ JDK 17 ขึ้นไป (โปรเจกต์ใช้ AGP 8.7.3 / compileSdk 35)

## อัปเดตจาก GitHub (0.5)

ติดตั้งรุ่น 0.5 ทับรุ่นเดิมหนึ่งครั้ง หลังจากนั้นกด **อัปเดต** ด้านบน แอปอ่าน `downloads/latest.json` ผ่าน HTTPS จาก GitHub ถ้ามี versionCode สูงกว่า จะให้เปิดดาวน์โหลด APK ด้วยเบราว์เซอร์ แล้วผู้ใช้กดยืนยันอัปเดตใน Android โดยไม่ต้องถอนแอป

### การปล่อยรุ่นต่อไป

1. เพิ่ม versionCode และ versionName ใน `app/build.gradle`, `build-apk.ps1` และข้อความหัวแอปให้ตรงกัน
2. สร้างด้วย `build-apk.ps1` และ **ใช้กุญแจเดิม** ที่ `build/manual/debug.keystore` เสมอ เพื่ออัปเดตทับรุ่นที่ติดตั้งไปแล้วได้ เก็บสำรองกุญแจนี้แบบส่วนตัว ห้ามนำขึ้น GitHub
3. คัดลอก APK ไป `downloads/MangaCapture-v<versionName>.apk` แล้วแก้ `downloads/latest.json` ให้ตรง
4. ทดสอบ ตรวจลายเซ็น และอัปโหลดทั้ง APK และ latest.json ใน commit เดียวกัน

ไฟล์ APK เป็นไฟล์เผยแพร่ที่ใส่ Git ได้ แต่กุญแจลงนามถูกตัดออกด้วย `.gitignore` การอัปเดตนี้ยังต้องยืนยันใน Android แต่ไม่ต้องลบแอปเดิม ไม่ได้สร้าง APK อัตโนมัติบน GitHub เนื่องจากกุญแจลงนามเก็บอยู่เฉพาะเครื่องพัฒนา
