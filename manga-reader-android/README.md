# Manga Reader · Android 0.1

แอปส่วนตัวสำหรับอ่าน PDF มังงะบน Android 8 ขึ้นไป ใช้ application ID `com.mangareader.app` แยกจาก Manga Capture

## ใช้งาน

ไฟล์ติดตั้ง: `build/manual/MangaReader.apk`

- กด **เปิด** แล้วเลือก PDF จากแอปไฟล์ของ Android หรือเลือก **เปิดด้วย Manga Reader** จากไฟล์ PDF
- เลื่อนขึ้นลงเพื่ออ่านต่อเนื่อง รองรับทั้ง PDF หน้า A4 และหน้ายาวจาก Manga Capture
- จีบนิ้วเพื่อซูม 1–3 เท่า ลากเพื่อเลื่อน และแตะสองครั้งเพื่อสลับซูม
- แตะภาพหนึ่งครั้งเพื่อซ่อน/แสดงแถบเครื่องมือและอ่านเต็มจอ
- จำหน้าและตำแหน่งในหน้าที่อ่านล่าสุด เปิดครั้งถัดไปจะอ่านต่อ
- ปุ่ม **ล่าสุด** แสดงไฟล์ที่เคยอ่านสูงสุด 20 ไฟล์
- แถบด้านล่างเลื่อนตำแหน่งทั้งเล่มได้ และแตะเลขหน้าเพื่อกระโดดไปหน้าที่ต้องการ
- เมนูปรับความสว่างเฉพาะแอป และเปิด/ปิดหน้าจอค้างระหว่างอ่าน

## การเก็บข้อมูล

ไม่ขอสิทธิ์อินเทอร์เน็ต ไม่อัปโหลด PDF และไม่ขอเข้าถึงไฟล์ทั้งเครื่อง ใช้ไฟล์ที่ผู้ใช้เลือกผ่านตัวเลือกไฟล์ Android เท่านั้น เก็บสำเนาเอกสารที่กำลังอ่านไว้ใน cache ของแอปเพื่อรองรับแหล่งไฟล์ที่ไม่ให้เลื่อนอ่านโดยตรง สำเนานี้จะถูกแทนที่เมื่อเปิดเรื่องอื่น ประวัติเก็บเพียงชื่อ URI และตำแหน่งอ่านในเครื่อง

ไฟล์จากคลาวด์อาจต้องดาวน์โหลดผ่านแอปผู้ให้บริการไฟล์ก่อน หากไฟล์ถูกย้ายหรือลบ ให้เลือกไฟล์ใหม่

## การแสดงผล PDF หน้ายาว

ใช้ Android PdfRenderer แสดงเฉพาะส่วนภาพที่อยู่ในจอ แบ่งเป็นแถบไม่เกิน 2,048 × 512 px และ cache สูงสุด 24 MiB ไม่สร้าง bitmap เต็มหน้ายาว การเรนเดอร์ทำบน worker เดียวเพื่อเปิด PdfRenderer.Page ครั้งละหน้า

## ตรวจสอบและข้อจำกัด

สร้างและตรวจลายเซ็น APK แล้ว ทดสอบการคำนวณตำแหน่งหน้าและการแบ่งภาพบน JVM ยังไม่ได้ทดสอบการแสดงผลและท่าทางบนมือถือจริงหรือ emulator

รุ่นแรกไม่รองรับรหัสผ่าน PDF, การค้นหาข้อความ, การเขียนโน้ต หรือการซิงก์ข้ามเครื่อง ความละเอียดขณะซูมจำกัดด้านกว้าง 2,048 px เพื่อควบคุมหน่วยความจำ
