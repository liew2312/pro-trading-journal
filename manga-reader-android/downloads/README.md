# Manga Reader สำหรับ Android

[ดาวน์โหลด Manga Reader 0.1](https://raw.githubusercontent.com/liew2312/pro-trading-journal/main/manga-reader-android/downloads/MangaReader-v0.1.apk)

เปิดไฟล์ APK บนมือถือ Android 8 ขึ้นไปแล้วติดตั้ง แอปแยกจาก Manga Capture ใช้สำหรับอ่าน PDF ในเครื่อง

กด **เปิด** เลือกไฟล์ PDF แล้วเลื่อนอ่านได้ทันที จีบนิ้วเพื่อซูม แตะภาพเพื่ออ่านเต็มจอ มีประวัติไฟล์และจำตำแหน่งอ่านล่าสุด

รุ่นทดลอง สร้างและตรวจลายเซ็นผ่านแล้ว ยังไม่ได้ทดสอบบนมือถือจริง แอปไม่ขอสิทธิ์อินเทอร์เน็ต
